# 四层框架图模板

本用户偏好的 OiiOii 式四层色块框架，使用 [可编辑 SVG 底稿](../assets/four-layer-framework.svg)。底稿保留 LibTV 样例文字以展示排版，使用时必须替换为当前产品内容；示例不是其他产品的事实。

## 版式

画布 1590 × 1250，左侧层名，右侧分组容器。用户层浅蓝、应用层浅黄、模型层浅紫、基础层灰蓝。容器使用细边框，内部卡片统一高度、圆角与间距。

| 层级 | 组织方式 |
| --- | --- |
| 用户层 | 横排核心入口、项目与资源等功能 |
| 应用层 | 左侧核心职责，右侧工具与控制 |
| 模型层 | 按图片、文本/规划、音频、视频等实际类别分组 |
| 基础层 | 资产与方法、项目数据分组 |

标题约 32 px、层名 27 px、组标题 21 px、卡片文字 19 px。内容过多时扩展画布或拆分，不持续缩小字号。

## 内容替换

从正文提取实际入口、职责、工具、模型和资产，替换底稿所有产品名称与标签。按当前产品增删组和列数，非视频产品不强留音视频分组。未知型号简短注明未披露；不能照搬样例的模型、RAG、知识库、自研能力或 Agent 数量。

整体框架以分组为主；执行顺序另画流程图。产品结构图可用“入口—规划编辑—执行交付”三栏，上方共享上下文，下方资产复用与反馈通道；减少折线，不让连线穿过文字。

## 交付

保存编辑后的 SVG，导出 PNG 嵌入报告。逐张查看文字、间距、裁切与连线，核对图文一致。修改后同步更新正文引用和打包文件。未经内容替换的底稿不能作为最终产品图交付。
